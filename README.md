## Deployment on GitHub Pages

1. Create a GitHub repository.
2. Upload your site files.
3. Rename your main file to `index.html`.
4. Go to **Settings** > **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Save and wait for GitHub Pages to publish the site.

If your repository name is not `yourusername.github.io`, your site URL will usually be:

`https://yourusername.github.io/repository-name/`

## Important Notes

- The homepage file should be named exactly `index.html`.
- File and folder names are case-sensitive on GitHub Pages.
- If your HTML references CSS, JavaScript, images, or fonts, those files must also be uploaded.
- If the site shows a 404 page, check the repo name, Pages settings, and file placement.
